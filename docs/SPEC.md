# Спецификация: «Никич: Путь к Пиву»

Статус: утверждена. Версия 2.1, 2026-11-05 (рендер 1920×1080, лицо Никича из фото).
Термины — по [GLOSSARY.md](../GLOSSARY.md). Если спека и глоссарий расходятся, правим тот, что устарел, а не код.

Эта спека — главный ориентир разработки. Любое отклонение от неё сначала согласуется с заказчиком и вносится сюда, а уже потом в код.

---

## 1. Суть

Браузерный 2D-платформер сбоку, игра-стёб для своей компании. Игрок ведёт Никича слева направо по Варшаве через 5 Уровней от Дома Никича (ul. Stańczyka) до бара U Sióstr (Złota 63A). Никич бегает, прыгает по платформам и отбивается от Зожников, которые лезут на него как зомби. В конце бьётся с G-man (самим собой в костюме) и получает Пиво.

| Параметр | Решение |
|---|---|
| Платформа | Браузер, только ПК (клавиатура + мышь). Мобильные не поддерживаются |
| Рендер | Canvas 2D, без WebGL. Опционально в конце — WebGL-проход постобработки (CRT, виньетка, «пьяное» плавание) |
| Жанр и вид | Платформер сбоку, гравитация и прыжки, прокрутка слева направо |
| Язык | Русский, тон — жёсткий дружеский стёб |
| Длина | 5 Уровней по 2–3 минуты, вся игра 10–15 минут |
| Хостинг | GitHub Pages, публичный репозиторий `nikich-beer` |
| Сборка | Нет. `index.html` + ES-модули, ноль зависимостей в рантайме |

## 2. Границы контента (обязательны)

- Не трогаем близких Никича.
- Без номера дома и квартиры: только «Дом Никича, Stańczyka».
- Фото с посторонними людьми не используем. Исключение — фото с девушкой: из него вырезаем только силуэт Никича.
- Армейское фото (форма, оружие) не используем. Шутка «как я в армухе уазик водил» — только нарисованным пиксель-артом.
- G-man — собственный пиксель-арт по фото Никича в костюме. Никаких ассетов, звуков, музыки и цитат дословно из Half-Life, только пародийная отсылка.
- Музыка и звуки — только сгенерированные в коде, никаких чужих треков.
- Оригиналы фото и видео в репозиторий не попадают (папка `raw/` в `.gitignore`).

## 3. Управление

| Ввод | Действие |
|---|---|
| A / D | Бег влево / вправо |
| W или Пробел | Прыжок (зажать — выше) |
| S | Спрыгнуть с тонкой платформы вниз |
| Мышь | Прицел на 360°: Никич разворачивается в сторону курсора |
| ЛКМ (зажать) | Щелбан — очередь окурков в сторону курсора |
| ПКМ | Собака — бежит в сторону курсора и вцепляется в первого Зожника |
| E | 5:0 — оглушение вокруг |
| R | «Папа сейчас всё сделает» (когда шкала полная) |
| Esc | Пауза |
| M | Звук вкл/выкл (запоминается) |
| 1 / 2 / 3 или клик | Выбор Улучшения |

Автоприцела нет. Курсор рисуется игрой (пиксельный прицел), системный курсор скрыт над Canvas.

## 4. Экраны и поток

```
Титульный → Заставка G-man → Уровень N → Выбор Улучшения → Заставка G-man → Уровень N+1 … → Уровень 5 (босс) → Финал → Титры
                                  ↓ (жизни кончились или вышел таймер)
                              Проигрыш → «Ещё раз» → тот же Уровень N
```

- **Титульный**: название, пиксельный портрет Никича, «Начать» или «Продолжить», если есть сохранение.
- **Заставка G-man**: G-man-Никич в костюме с портфелем, 2–4 реплики-стёба про следующий Уровень, пропуск по клику.
- **Выбор Улучшения**: 3 случайные карточки, у каждой название, эффект и подпись-стёб.
- **Проигрыш**: пикселизированное фото «на полу», «Я гнию изнутри» и случайная фраза из пула, кнопка «Ещё раз».
- **Финал**: дверь U Sióstr открывается, Никич берёт кружку, крупный портрет довольного Никича. Статистика: Зожников уложено, стопариков выпито, смертей, время.
- **Титры**: в стиле вступления космической саги, но без её цитат и музыки — звёзды, голубая строка «Не так давно, в не такой уж далёкой Варшаве…», логотип «НИКИЧ / ПУТЬ К ПИВУ», уходящий вдаль, затем жёлтый текст в перспективе: «Эпизод V», история, «В РОЛЯХ», все фразы Никича, благодарность. Клик — промотать, потом «Ещё раз» (новая игра с нуля). Тексты — `CRAWL` в lines.js.

## 5. Никич

| Параметр | Старт |
|---|---|
| Жизни | 3 на Уровень (восстанавливаются в начале каждого Уровня) |
| Здоровье | 100 на жизнь |
| Скорость бега | 110 px/с (в мировых пикселях) |
| Прыжок | Высота ~3,5 тайла при полном зажатии, ~1,5 тайла при коротком нажатии |
| Гравитация | 900 px/с² |
| «Койот-тайм» | 0,1 с: можно прыгнуть сразу после схода с края |
| Буфер прыжка | 0,1 с: нажатие чуть раньше приземления засчитывается |
| Неуязвимость после удара | 1 с, с отбрасыванием назад |
| Падение в яму | Минус одна жизнь, возврат на последнюю контрольную точку |

Спрайт — тело пиксель-артом 16×24, голова — вырезка из фото (пляж, авиаторы) в полном разрешении рендера, вид сбоку (влево — зеркальное отражение). Голова меняет выражение по событиям, каждое — своё фото из `raw/faces/` (заказчик прислал вырезанными): обычное — ухмылка (худи); Зожник ближе 72 px — косится; Щелбан, Собака, 5:0, Папа — злой (кулак); убийство, Фишка, пройденная Запертая волна, победа — хохочет; Стопарик и мало здоровья — хохочет с царапиной; урон, Яма, оглушение — щурится (фото 8, чужое лицо в углу вырезано); хот-дог — сытая улыбка (жилетка); сигарета — курит; прыжок — запрокинул голову (фото 6); Пиво 0,0 — «уточка» (фото 1, только голова Никича). HUD показывает то же выражение. G-man — так же, голова из фото в костюме. Анимации: стоит, бежит, прыжок, падение, удар, получил урон, лежит. Типичный образ по фото: тёмные зачёсанные волосы, круглое лицо, авиаторы, серая футболка, бежевые шорты.

Над головой Никича всплывают реплики при событиях (см. §12).

### 5.1 Атаки

| Атака | Ввод | Эффект (старт) | Перезарядка |
|---|---|---|---|
| **Щелбан** | ЛКМ зажать | Окурок летит по прямой к курсору, урон 10, скорость 300 px/с, дальность 220 px | 0,25 с |
| **Собака** | ПКМ | Собака бежит по земле в сторону курсора и вцепляется в ногу первого Зожника: урон 15/с, он обездвижен 3 с | 6 с |
| **5:0** | E | Оглушение 1,5 с всем Зожникам в радиусе 70 px, урон 5 | 5 с |
| **Папа сейчас всё сделает** | R | Урон 200 всем Зожникам на экране, вспышка, тряска экрана | Шкала: +1 за каждый урон, полная = 100 |

Собака визуально: пиксельная собака, которая на 3 с пристраивается к ноге Зожника.

## 6. Зожники

Все Зожники подчиняются гравитации, ходят по платформам, сами не прыгают в Ямы (кроме Мотоциклиста на трамплине), но спрыгивают с уступов до 4 тайлов, чтобы добраться до Никича.

| Вид | Здоровье | Скорость | Урон | Поведение |
|---|---|---|---|---|
| **Бегун** | 20 | 70 | 10 касанием | Бежит к Никичу, перепрыгивает низкие препятствия |
| **Велосипедист** | 30 | 140 рывком | 20 касанием | Разгоняется по горизонтали через весь экран, потом тормозит 1 с |
| **Мотоциклист** | 60 | 170 рывком | 30 касанием | Как Велосипедист, но с трамплинов прыгает дугой; шутки про мотоциклистов |
| **Йога-тётка** | 40 | 30 | 5 касанием | Медленная, стоит в позе на платформе. Рядом с Никичем читает «лекцию про чакры»: Никич оглушён 1 с |
| **Смузи-хипстер** | 25 | 45 | 10 снарядом | Держит дистанцию, кидает смузи по дуге |

- Зожники твёрдые: не проходят сквозь Никича, упираются в него (у стены отодвигают Никича); перепрыгнуть сверху можно. Ударив касанием, Зожник отскакивает и 1,6 с не бьёт снова.
- Появляются из-за правого края экрана, из дверей подъездов и магазинов и в «точках появления» на карте.
- С убитого Зожника с шансом 10% выпадает **Пиво 0,0**.
- Убийство Зожника засчитывается в статистику.

## 7. Предметы

| Предмет | Тип | Эффект |
|---|---|---|
| Хот-дог из Żabki | Бонус | +30 здоровья (сверх максимума — не даёт) |
| Стопарик водки | Бонус | +25% урона на 8 с, лёгкое «плавание» экрана; считается в статистику |
| Сигарета | Бонус | +15 с к таймеру Уровня («перекур») и Затяжка на 6 с: бег ×1,3, прыжок выше на 30%, Щелбан в 1,6 раза чаще. На бегу экран размывается по ходу движения, как в гонках: шлейф-призрак, полосы скорости, затемнение по краям |
| Покерная фишка | Бонус | Удача на 10 с: каждый удар Зожника или G-man (касание, смузи, портфель, 5:0) с шансом 50% — промах, без урона; после промаха 0,6 с передышки. Над головой промахнувшегося всплывает и тает «Промах». Подпись «Легендарная игра». Очков в игре нет |
| **Пиво 0,0** | Ловушка с бонусом | Здоровье не трогает. Каждое Пиво подряд — +1 к Опьянению (до 4). С каждым уровнем: бег −13%, разгон вязче, прыжок ниже, прицел запаздывает, экран сильнее размыт, качается и покручивается. Зато Щелбан +15% урона и удары Зожников −10% за уровень. Через 5 с уровень уходит, дальше — по одному каждые 2,5 с. Реплика «Мы только по пиву… это не пиво, сука». Выглядит как банка любимого пива Никича — Książęce Złote Pszeniczne (`assets/img/beer-can.png`, вырезана из фото заказчика) |
| **Самокат** | Транспорт | Сел наездом. Скорость ×2, прыжок выше на 50% (перелетает ямы и барьеры), сбивает Зожников (урон 30). 10 с или до удара о стену, потом Никич падает лицом в асфальт (оглушён 1 с) |

Бонусы висят в воздухе или лежат на платформах в фиксированных точках Уровня, часть — в труднодоступных местах (награда за прыжки), и иногда выпадают из Зожников.

## 8. Улучшения

После каждого пройденного Уровня (кроме последнего) Игрок выбирает 1 из 3 случайных Улучшений без повторов в одной тройке. Улучшения копятся и сохраняются после проигрыша.

Стартовый пул:

| Улучшение | Эффект |
|---|---|
| Сало в крови | +10 к макс. здоровью |
| Тяжёлая рука | +10% к урону всех атак |
| Опаздывает в бар | +10% к скорости бега |
| Курит как паровоз | Щелбан на 15% быстрее |
| Папа на подходе | Шкала супера копится на 20% быстрее |
| Злая собака | Собака держит на 1 с дольше |
| Магнит для халявы | Бонусы притягиваются с 80 px |
| Прокатчик | +1 Самокат на каждом Уровне |
| Железная печень | Пиво 0,0 действует вдвое короче |
| 5:0 в нашу пользу | Радиус 5:0 +20% |
| Прыгучий | Двойной прыжок |

Подписи-стёб — в `src/lines.js`.

## 9. Уровни

Каждый Уровень — горизонтальная прокрутка слева направо. Камера следует за Никичем с упреждением по направлению бега, вертикально сглажена.

| # | Место | Платформы и препятствия | Зожники | Особенность |
|---|---|---|---|---|
| 1 | Дом Никича, Stańczyka | Подъезд, лестница, двор, крыши припаркованных машин, мусорные баки | Бегуны | Обучение: без ям, простая раскладка (управление — на экране Паузы) |
| 2 | Rondo Daszyńskiego | Строительные леса, бетонные блоки, ямы стройки, козырьки офисов | Бегуны, Смузи-хипстеры | Первые ямы |
| 3 | Hala Mirowska | Прилавки, ящики, тенты, крыша трамвая | Йога-тётки, Бегуны, Смузи | Первые Самокаты, движущийся трамвай как платформа |
| 4 | PKiN / Złote Tarasy | Ступени Дворца культуры, фонари, стеклянная крыша Złotych Tarasów | Велосипедисты, Мотоциклист с трамплинами, все остальные | Длинные пролёты, рывки по горизонтали |
| 5 | Złota 63A, U Sióstr | Арена в один экран: улица у бара, 3 платформы | Призываемые G-man | Бой с G-man |

- Таймер Уровня: 180 с (Уровень 5 — без таймера, только жизни). Пока идёт Запертая волна, таймер стоит.
- Запертые волны: 2–3 на Уровнях 1–4, участок 15–26 тайлов без Ям и Контрольных точек. Никич вошёл — ворота с обеих сторон закрылись, Зожники выходят из ворот волнами (2 волны по 2–3), Йога-тётки — сразу в атаку; все убиты — ворота открыты. Волна держит не дольше 12 с: застрявшие Зожники остаются, но ворота идут дальше. Потерял жизнь — Запертая волна, если не пройдена, начнётся заново. Виды Зожников — те же, что на Уровне.
- Уровень пройден, когда Никич дошёл до зоны выхода справа (на Уровнях 1–4). Убивать Зожников не обязательно.
- Контрольные точки: 2–3 на Уровень, возврат на них после падения в яму или потери жизни.
- Карты — тайловые массивы в `src/levels/*.js`, тайл 16×16, высота 17 тайлов (под экран 270 px), длина порядка 150–220 тайлов.
- Типы тайлов: сплошной, тонкая платформа (можно запрыгнуть снизу и спрыгнуть через S), барьер (перепрыгивается только на Самокате), яма, декор фона.
- Фон — 2–3 слоя параллакса с силуэтами Варшавы (Varso, Spire, PKiN).

## 10. G-man

**В заставках**: появляется между Уровнями с портфелем и комментирует успех или провал Никича.

**Финальный бой** (Уровень 5, арена в один экран с 3 платформами), здоровье 600, 3 фазы по 200. Каждая фаза начинается с того, что G-man выпивает **Креатинчик** (пауза 1,5 с, анимация, реплика, он неуязвим):

1. **Портфель**: телепортируется между платформами, кидает портфель по дуге.
2. **Призыв**: стоит на верхней платформе, призывает волны Зожников (раз в 4,5 с), комментирует. После каждой волны 2,5 с его закрывает видимый щит-пузырь (или пока живы Зожники волны, если их уложить раньше); дальше его можно бить, даже если кто-то из Зожников застрял.
3. **Зеркало**: копирует атаки Никича — Щелбан и 5:0, прыгает следом за ним. Никич бьётся сам с собой.

**Победа**: G-man поправляет галстук, растворяется по пикселям, дверь U Sióstr открывается → Финал.

## 11. Сохранение

`localStorage`, ключ `nikich-beer:save:v1`:

```json
{ "level": 3, "upgrades": ["salo", "heavy-hand"], "stats": { "kills": 0, "shots": 0, "deaths": 0, "timeMs": 0 } }
```

- Пишется после выбора Улучшения и при проигрыше.
- Чтение и запись обёрнуты в try/catch: без хранилища игра работает, просто не продолжает.
- «Новая игра» на титульном экране стирает сохранение после подтверждения.

## 13. Графика

- Логическое разрешение 480×270 (физика, карты, интерфейс), рендер 1920×1080 (×4), канвас вписывается в окно с сохранением 16:9, F — полный экран. `imageSmoothingEnabled = false`, кроме уменьшаемых фото.
- **Производительность** (решение заказчика 2026-11-06, жалобы игроков на тормоза; цель — плавно на мониторах 30–240 Гц и на слабых ПК):
  - Логика — фиксированный шаг 1/60 с, не зависит от частоты монитора. Отрисовка во время игры **интерполирует** позиции (Никич, Зожники, G-man, Собаки, снаряды, Предметы, Трамваи, камера) между двумя последними шагами — без рывков на 30/50/75/144 Гц. Скачок больше `LOOP.snapDistance` за шаг (телепорт G-man, возврат на Контрольную точку) не сглаживается.
  - Вне игры (меню, Пауза, Заставки) кадр рисуется только после шага логики — на мониторах выше 60 Гц нет одинаковых кадров.
  - Догонялка: за кадр не больше `LOOP.maxFrame` = 0,1 с логики (6 шагов). Если ПК не успевает, игра немного замедляется, а не «телепортирует» Никича.
  - Объекты за пределами кадра не рисуются.
  - Без фильтров канваса и CSS: мигание при уроне — повторная отрисовка в режиме `lighter`; размытие при Опьянении — уменьшенная копия мира поверх с прозрачностью по стакам (HUD не размывается), покачивание и наклон — CSS `transform`.
  - Кэши отрисовки (фаза 2, решение заказчика 2026-11-06): текст HUD, табличек и реплик рисуется один раз в картинку и дальше копируется (кэш на `RENDER_CACHE.textEntries` строк, старые вытесняются); тайлы Уровня собираются в куски по `RENDER_CACHE.chunkTiles` тайлов (в памяти не больше `RENDER_CACHE.chunkKeep` кусков у камеры); неподвижные части панели навыков (полосы, грифоны) — готовые картинки в размере экрана; Зожники в обычных позах (стоят, идут, бегут, в прыжке) — кадры из кэша, фаза шага округляется до `RENDER_CACHE.gaitFrames` кадров на цикл. Картинка не должна заметно отличаться от рисования напрямую.
  - Замер: `?bench` (можно с `&hz=30` / `&hz=50` — ограничение частоты кадров) — сцена на Уровне 4 с 12 Зожниками и Опьянением, итог в консоли и на экране.
- Персонажи — скелетная векторная анимация в коде (`src/rig.js`, `src/art.js`): шаг и бег по пройденному пути, прыжок, атаки, оглушение, падение при смерти. Тайлы — процедурные текстуры под каждую локацию (`src/tiles.js`: Wola, стройка, Hala Mirowska, PKiN, Złota), рисуются один раз в разрешении рендера. Персонажи рисуются вправо, влево — зеркально.
- Фон (`src/backdrop.js`) — 3 слоя по реальным местам и время суток по пути к бару: утро (Stańczyka: новостройки, краны), день (Rondo: Warsaw Spire, Skyliner, Varso, метро), после обеда (Hala Mirowska, каменицы), закат (PKiN, Złota 44, Złote Tarasy), ночь (Złota). Сглаживание картинок — только `low`, иначе падает fps.
- Уличный декор (`src/props.js`) — по фото варшавских улиц: деревья в решётках, фонари (современные и старые), остановки ZTM со стеклом и постером, урны и сортировка, скамейки, рекламные тумбы, билборды, станции Veturilo, киоски, конусы и заборы стройки, прилавки с фруктами, клумбы, Сиренка, «I ❤ Warszawa», неон. Набор и веса — в `THEME.props` каждого Уровня; расстановка детерминированная, только на свободной земле, не ближе 2 тайлов к дверям, флажкам, воротам, старту и выходу. Спрайты рисуются один раз в разрешении рендера; на закате и ночью фонари и неон светятся. Плюс магазины Żabka (зелёная вывеска с логотипом «żabka» и улыбкой, выносной короб, полки, дверь «24/7», ночью светится зелёным) — минимум 2 на Уровнях 1–4 и 1 на Арене, и вывески Żabki на фоновых домах; витрины других магазинов с вывеской и маркизой, рекламные лайтбоксы, стены с афишами. На фоновых домах (кроме дальнего слоя): вывески магазинов на первых этажах, рекламные баннеры во весь фасад, билборды на крышах и стеклянных башнях, ночью светятся. Все надписи только по-польски. Плакаты — 20 настоящих польских рекламных плакатов и афиш с Wikimedia Commons (источники — `tools/posters.json`). Оригиналы — `raw/posters/` (не коммитятся), игровые копии делает `tools/posters.py` в `assets/img/posters/`. Вывески — `SHOP_SIGNS`, неон — `NEON_SIGNS` в lines.js; всё рисует `src/signs.js`.

### HUD (в стиле WoW)

Оформление — настоящие текстуры интерфейса WoW из пака [Gethe/wow-ui-textures](https://github.com/Gethe/wow-ui-textures) (для личного использования), лежат в `assets/wow/`, загрузка и нарезка — `src/wow.js`.

- `src/hud.js`: рамка Никича — зеркальная классическая рамка цели (`UI-TargetingFrame`): портрет в кольце с текущим выражением, номер Уровня в малом кольце, здоровье зелёным, шкала Папы синим как «мана», белый «хвост» уходящего здоровья, мигание кольца при малом здоровье. Ниже сердечки жизней и баффы с иконками WoW и таймерами (Стопарик, Пиво ×N, Затяжка, Самокат).
- Рамка цели: G-man в бою — «элитная» рамка с драконом, череп вместо уровня, деления фаз, щит мигает; иначе последний Зожник, по которому попал Никич (4 с), с его фигуркой в портрете и подписью «Зожник N-го уровня» (класс зелёным, уровень белым, как в WoW).
- Панель внизу — полосы `UI-MainMenuBar-Dwarf` с 12 ячейками и каменными грифонами по краям, в окне полосы опыта — фиолетовый прогресс по Уровню. В ячейках иконки WoW: Щелбан, Собака, 5:0, Папа и взятые Улучшения. Клавиша в углу, перезарядка — тёмный сектор с яркой кромкой и отсчётом, вспышка-звезда при готовности, «вдавливание» и подсветка при нажатии, «муравьи» и свечение у полной шкалы Папы, красный оттенок при оглушении.
- Неймплейты WoW над Зожниками и G-man (имя, полоска, уровень или череп); у цели — подсветка. До боя G-man — зелёная подпись NPC «<Наблюдатель>». Над головой Никича — такая же полоска здоровья с тонкой полоской Папы, реплики — облачком чата WoW выше неё.
- Таймер Уровня и «Волна N/M» — справа сверху. Строка «Оглушён» убрана — вместо неё Значок эффекта.
- Меню и экраны (титул, Пауза, Улучшения, Проигрыш, Уровень пройден, Финал, Заставки) — окна `UI-DialogBox` с заголовком-плашкой, красные кнопки `UI-Panel-Button`. Цвета: золотой #ffd100 для имён и заголовков, зелёный для класса и эффектов, белый — текст, серый — второстепенное.
- Шрифт — Friz Quadrata с кириллицей (`assets/fonts/frizqt___cyr.ttf`, как в русском клиенте WoW), без жирного начертания; недостающие знаки (польские) — из Optima/Candara/Segoe UI.
- Мир не уходит под панель: он рисуется в области над ней (высота экрана минус панель) в масштабе ~0,88, вся высота Уровня видна, по ширине видно больше. Полоса под панелью — деревянная полка с рядом банок Książęce (та же банка, что у Пива 0,0), грифоны и панель стоят поверх.
- Значки эффектов под портретом: верхний ряд — полезные (Стопарик, Пивная сила со стаками, Затяжка, Самокат, Легендарная игра — Удача после Фишки), нижний, в красной рамке WoW, — вредные (Опьянение со стаками, Оглушение). Таймер под значком, мигает в последние 3 с.
- Подсказка при наведении курсора на навык, Улучшение или Значок эффекта — тултип WoW: название, перезарядка, что делает (числа из баланса), сколько осталось.
- Таблички с управлением на Уровне убраны (решение заказчика), управление — на экране Паузы.

## 14. Звук

WebAudio, всё генерируется в коде (`src/audio.js`):
- Чиптюн-петля на каждый Уровень и отдельная на босса.
- Звуки: прыжок, приземление, щелчок Щелбана, лай Собаки, «5:0», «бульк» стопарика, рёв мотоцикла, удар по Никичу, падение в яму, победа.
- Звук включается после первого клика (политика автоплея браузеров). Громкость и mute — на паузе.
- Голос Никича — §16, последним этапом.

## 15. Архитектура

```
index.html
src/
  main.js        игровой цикл (фикс. шаг 1/60), машина экранов
  config.js      все числа баланса из этой спеки
  input.js       клавиатура и мышь
  physics.js     гравитация, прыжок, коллизии с тайлами (сплошные, тонкие платформы)
  world.js       тайловая карта, камера, параллакс, контрольные точки
  nikich.js      Никич, здоровье, жизни, атаки
  zozniki.js     виды Зожников, поведение, появление
  items.js       Бонусы, Пиво 0,0, Самокат
  upgrades.js    пул Улучшений, выбор 1 из 3
  gman.js        заставки и бой G-man
  levels/        level1.js … level5.js
  art.js         пиксель-арт
  audio.js       музыка и звуки
  save.js        localStorage
  lines.js       все тексты
  ui.js          HUD и экраны
assets/img/      портреты из фото
raw/             оригиналы фото и видео (в .gitignore)
tools/pixelize.py
tests/*.test.js  node --test
```

Правила кода:
- Все числа баланса — только в `src/config.js`, в логике нет «магических» чисел.
- Чистая логика (физика, коллизии, урон, пул Улучшений, сохранение, таймер, появление Зожников) не трогает DOM и Canvas, чтобы её тестировать в Node.
- Сбой загрузки картинки или звука не роняет игру: заглушка вместо картинки, тишина вместо звука.
- Идентификаторы в коде — на английском. Тексты в игре — на русском, термины — по глоссарию.
- Локальный запуск: `python -m http.server` (ES-модули не работают с `file://`).

## 16. Озвучка (последний этап)

- Никич в курсе и согласен на озвучку и клон голоса.
- Решение заказчика 2026-11-05: Голос Никича — вырезки из его собственных записей (2 видео и голосовое), а не синтез. Фразы и таймкоды выбрал заказчик. Исходники — в `raw/voice/` (не коммитятся), нарезка и нормализация громкости — `tools/voice.py` (`.venv/bin/python tools/voice.py`), результат — `assets/voice/*.wav`, 22 кГц моно.
- Расшифровка и таймкоды — локально whisper.cpp (`whisper-cli`, модель large-v3, пословные метки DTW); границы подогнаны к паузам между словами, каждый клип проверен повторной расшифровкой.
- Над головой реплики не меняются: голос звучит отдельно, по Голосовым группам событий. Числа и группы — в `src/config.js` (`VOICE`), проигрывание — `src/audio.js` (WebAudio, после первого клика или клавиши).
- Один «рот»: новая фраза не перебивает звучащую, кроме более важной (Пиво 0,0 и Хот-дог важнее боя, отбитая Запертая волна — важнее всего).

| Событие | Фраза | Ограничение |
|---|---|---|
| Первое Пиво 0,0 за Уровень (попытку) | «Всем привет! Это моя первая банка пива. Безалкогольная.» | — |
| Следующие Пиво 0,0 | «156 пиво.» | не чаще 20 с |
| Хот-дог (лечение) | «Я с утра въебал 2 литра нахуй, это было в 11 утра, блядь.» | — |
| Урон от Зожников и G-man | «Меня этот хохел хочет пиздить.» / «Этот хохел меня хочет уничтожить, бля.» | не чаще 20 с |
| Попадание по Зожнику | «Да мы его закопаем нахуй, ёбаный рот.» | не чаще 30 с |
| Зожник подошёл вплотную (48 px) | «Что ты, готов нахуй на улицу ехать, бля?» | не чаще 40 с |
| Запертая волна отбита | «Я вчера видел, как, блять, чувака лущили нахуй.» | — |

- Решение заказчика 2026-11-06 (фразы звучали слишком часто): после любой фразы — Общая пауза голоса 12 с, в неё звучат только первое Пиво 0,0, Хот-дог и отбитая Запертая волна. Ограничения в таблице — сверх паузы.
- Фраза «хохел» оставлена по решению заказчика.
- Не используются: реплики собеседников во втором видео, шум и музыка в конце первого видео.
- Клон голоса через MiniMax — запасной вариант для реплик, которых нет в записях (Заставки G-man): ключ в переменной окружения `MINIMAX_API_KEY`, ставит заказчик.
- Фрагменты с посторонними людьми и детьми не используются.
- Игра полностью работает и без озвучки.
